この付録は、講義「企業経営とAI」の教材全体の案内である。教材の使い方、全15巻の一覧、講義で共通に使う模擬企業、共通の用語、講義前に確かめる事項をまとめた。迷ったときは、まずここに戻ってほしい。

## A. この教材の使い方

### 概要版と詳細ガイドブックの関係

教材は2つの層でできている。

- **概要版（このドキュメント、全15章）**：講義の各回に1章が対応する。1章はA4で4〜6ページほどで、その回の要点・中心図・財務との接続・確認問題をまとめている。授業の前後に読む「地図」である。
- **詳細ガイドブック（全15巻）**：概要版の各章を、1巻25〜40ページで詳しく説明する。例、ケース、演習ワークシート、確認テストを含む。自分の会社や研究に当てはめるときに読む「案内書」である。

概要版の第N章と、詳細ガイドブックの第N巻は同じテーマを扱う。各章の最後にある「ガイドブックへの案内」に、その巻のどの章を読めばよいかを書いてある。

【ポイント】 2つの層をつなぐのが、最終課題の「AX Transformation Blueprint（AX計画書）」である。各巻の第10章で作る成果物が、計画書の1つの節になる。第15巻で、それらを1冊の計画書にまとめる（下のBの表を参照）。

### 読む順番：3つのルート

| ルート | 読む順番 | こんな人に |
| --- | --- | --- |
| 最短ルート | 概要版 第1章 → 第4章 → 第15章。詳細は第4巻と第15巻だけ | まず全体をつかみ、計画書の形を知りたい人 |
| 経営者ルート | 概要版の全章 → 第1巻 → 第4巻 → 第14巻 → 第13巻 → 第15巻（投資の判断が必要なら第7巻も） | 自社の計画書を書く経営者・管理職 |
| 院生・技術者ルート | 概要版の全章 → 第1〜4巻 → 関心のある巻を2巻以上（第5・6・9〜12巻から）→ 第15巻 | 模擬企業A社で計画書を書く大学院生・技術者 |
| 通読ルート | 概要版と第1〜15巻を順に | 講義全体を振り返りたい人 |

【例】 社員20名の会社の社長なら、経営者ルートで第1巻の自社診断から始め、第4巻で自社のROICツリーを描き、第14巻の90日パイロット計画を書けば、計画書の骨格ができる。

## C. 共通資産：模擬企業A社・B社・C社

講義では、3つの架空の会社を全巻で使う。どの会社も数字はプログラムで作り、貸借の一致と現金の流れの一致を確かめてある。

| 項目 | A社（標準版） | B社（小規模版） | C社（地域製造業版） |
| --- | --- | --- | --- |
| 業種 | B2Bの製造・商社（部品を仕入れて加工し、企業に販売） | 地域の食品加工・卸 | 山口県内の金属部品加工（切削部品） |
| 規模 | 売上 約30億円、従業員120名 | 売上 約3億円、従業員20名 | 売上 約7.5億円、従業員45名 |
| 売上高（2024→2025→2026年度） | 26億 → 28億 → 30億円 | 2.80億 → 2.95億 → 3.10億円 | 8.00億 → 7.80億 → 7.50億円 |
| ROIC | 8.4% → 6.3% → 4.4% | 9.2% → 6.8% → 4.3% | 11.8% → 7.2% → 3.9% |
| 投下資本 | 12.0億 → 14.6億 → 17.5億円 | 1.21億 → 1.29億 → 1.39億円 | 4.14億 → 4.66億 → 4.56億円 |
| CCC（現金化までの日数） | 55日 → 85日 → 115日 | 38.0日 → 43.6日 → 49.8日 | 50日 → 53日 → 57日 |
| 営業キャッシュフロー（2025→2026年度） | −0.63億 → −1.10億円 | +922万 → +571万円 | +7,377万 → +5,785万円 |
| EVA | +0.29億 → +0.04億 → −0.28億円 | +391万 → +108万 → −234万円 | +2,414万 → +563万 → −952万円 |
| 一人当たり付加価値 | 687万 → 675万 → 658万円 | 460万 → 443万 → 423万円 | 678万 → 644万 → 594万円 |
| 悪化の主な原因 | 売掛金と在庫が膨らみ、回転率が下がった | 大口取引先X社への依存（売上比率40%→55%）で粗利率が下がった（30%→26%） | 見積の回答が遅く受注率が下がり（32%→25%）、設備の稼働率が落ちて（78%→64%）固定費をまかなえない |
| AX成熟度 | 段階1 | 段階1 | 段階1 |

【ポイント】 3社とも3年間でROICが大きく下がり（A社は約半分、B社は半分以下、C社は約3分の1）、資本コスト（6%と仮定）を下回った。しかし、弱った枝が違う。A社は回転率（お金の回りの速さ）、B社は利益率（もうけの厚さ）、C社は稼働率と固定費である。同じ「ROICの悪化」でも、打つべき手が違うことを、この3社で確かめてほしい。

- A社の財務三表とROICツリーは、第4巻『財務ハブ：PL・BS・CFとROICツリー』にある。
- B社の3期分のデータ、ワークシートの記入例、第14巻で使う受注入力の90日パイロットの設定は、共通資産「模擬企業B社（小規模版）データ」にまとめてある。
- C社の3期分のデータと、第14巻で使う「AI見積支援」の90日パイロットの設定は、共通資産「模擬企業C社（地域製造業版）データ」にまとめてある。3社はROICが下がる原因の枝がそれぞれ違う（A社＝回転率、B社＝粗利率、C社＝稼働率と固定費）。

## D. 共通の用語集

講義全体で使う主な用語である。詳しい説明は「主に扱う巻」を見てほしい。

| 用語 | 意味 | 主に扱う巻 |
| --- | --- | --- |
| AX | AIを前提に、人とAIの役割や仕事の流れを作り直し、事業や組織まで変えること | 第1巻 |
| AX成熟度（5段階） | AIの使い方の深さ。①個人利用、②業務組込み、③半自律、④監督付き自律、⑤業務の再設計。段階2と3の間に大きな境目がある | 第1巻 |
| 6つの診断の観点 | 使い方の深さ、データ、業務の作り直し、財務での効果測定、ルールとガバナンス、人材と経営者の関与。各1〜5点で採点する | 第1巻 |
| 3本柱 | AI活用の3つの方向。①意思決定の高度化・高速化、②業務プロセスの自律化、③新規事業の創出 | 第1巻 |
| 財務ハブ | AIの効果を、利益・現金・お金の使い方の効率（ROIC）で測る考え方。本講義の中心 | 第1巻・第4巻 |
| 情報の3色ルール | AIに入力してよい情報を信号機の色で分ける決まり。青＝認めたサービスなら入力可、黄＝上司の了解を得てから、赤＝入力しない | 第1巻（第10巻で解放表に発展） |
| ROIC | 投下資本利益率。NOPAT÷投下資本。事業に使っているお金100円あたり、年に何円稼いだか | 第4巻 |
| ROICツリー | ROICを「利益率×回転率」に分け、財務の指標、さらに現場で動かせる数字までつなげた図 | 第4巻 |
| NOPAT | 税引後営業利益。本講義では営業利益×（1−税率30%） | 第4巻 |
| 投下資本 | 事業に使っているお金。本講義では運転資本＋固定資産 | 第4巻 |
| 運転資本 | 売掛金＋在庫−買掛金。日々の商売のために寝ているお金 | 第4巻 |
| CCC | キャッシュ・コンバージョン・サイクル。売掛金回転日数＋在庫回転日数−買掛金回転日数。支払いから回収までの日数 | 第4巻 |
| 資本コスト | 事業に使うお金の「使用料率」。本講義では6%と仮定する | 第4巻・第7巻 |
| EVA | 経済的付加価値。NOPAT−投下資本×資本コスト。資本コストを超えて稼いだ額 | 第4巻・第7巻 |
| 一人当たり付加価値 | （営業利益＋人件費＋減価償却費）÷従業員数 | 第4巻・第10巻 |
| 活動KPI／財務KPI | 仕事のやり方の変化を測る指標（処理時間など）／利益・現金・お金の効率を測る指標（ROICなど） | 第4巻 |
| 転換の経路 | 浮いた時間や仕事の変化が、お金の変化に変わる道すじ。費用削減、売上増、採用回避、寝ているお金の回収の4つ | 第4巻・第7巻 |
| Jカーブ | 新しい技術を入れた直後に成果がいったん下がり、その後に上がる現象 | 第1巻・第7巻 |
| 4つの歯止め | AIを財務に使うときの決まり。KPI辞書、検証済みの計算、根拠の明示、権限と確定・速報の区別 | 第4巻・第5巻 |
| 予測と判断 | 意思決定を、AIが安くする「予測」と、人が担う「判断」（何を重視するか、誤りのコスト）に分ける考え方 | 第2巻 |
| ハルシネーション | 生成AIが、もっともらしいが誤った内容を出すこと | 第3巻 |
| ジャグド・フロンティア | AIが得意な仕事と苦手な仕事の境目が、ギザギザで見えにくいこと | 第3巻・第8巻 |
| RAG | 社内の文書を検索し、その内容をもとに答える仕組み | 第3巻・第10巻 |
| AIエージェント | 目標に向けて手順を続け、業務システムを実際に操作するAI | 第3巻・第11巻 |
| TCO／NPV | TCO＝導入から利用をやめるまでの総費用（社内の手間を含む）。NPV＝将来の現金の現在価値の合計から投資額を引いたもの | 第7巻 |
| トリアージ | 問い合わせを、AIで完結するもの・AIが下書きして人が確かめるもの・人が対応するものに分けること | 第9巻 |
| 解放表 | 仕事ごとに、情報の色とAIに任せる段階（読む→下書き→提案→承認付き実行→実行）を決めた表 | 第10巻 |
| 権限表・承認点 | AIエージェントに何を許すかを決めた表と、人が承認しないと先に進まない地点 | 第11巻 |
| 三線モデル | リスク管理の責任を、現場（第1線）、管理部門（第2線）、内部監査（第3線）に分ける考え方 | 第13巻 |
| 90日パイロット | 1つの業務で小さく試し、成功の基準と中止の基準を決めて90日で確かめる進め方 | 第14巻 |
